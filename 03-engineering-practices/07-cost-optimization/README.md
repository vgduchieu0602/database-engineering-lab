# Cost Optimization

## 1. Tổng quan

Cost Optimization thuộc [Engineering Practices](../README.md), tập trung vào năng lực cần dùng khi làm việc với dữ liệu thực tế.

## 2. Tại sao cần học?

Kiến thức này giúp tránh quyết định kỹ thuật dựa trên giả định và tạo đầu ra dữ liệu có thể kiểm chứng.
