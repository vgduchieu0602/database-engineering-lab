# Docker

## 1. Tổng quan

Docker thuộc [Engineering Practices](../README.md), tập trung vào năng lực cần dùng khi làm việc với dữ liệu thực tế.

## 2. Tại sao cần học?

Kiến thức này giúp tránh quyết định kỹ thuật dựa trên giả định và tạo đầu ra dữ liệu có thể kiểm chứng.

## 3. Kiến thức sẽ học

| Concept | Nội dung sẽ học | Ứng dụng |
|---|---|---|
| Images | Khái niệm Images: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Images để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Containers | Khái niệm Containers: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Containers để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Volumes | Khái niệm Volumes: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Volumes để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Networks | Khái niệm Networks: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Networks để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Reproducibility | Khái niệm Reproducibility: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Reproducibility để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
