# Cloud Fundamentals

## 1. Tổng quan

Cloud Fundamentals thuộc [Engineering Practices](../README.md), tập trung vào năng lực cần dùng khi làm việc với dữ liệu thực tế.

## 2. Tại sao cần học?

Kiến thức này giúp tránh quyết định kỹ thuật dựa trên giả định và tạo đầu ra dữ liệu có thể kiểm chứng.

## 3. Kiến thức sẽ học

| Concept | Nội dung sẽ học | Ứng dụng |
|---|---|---|
| Compute | Khái niệm Compute: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Compute để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Object Storage | Khái niệm Object Storage: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Object Storage để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Managed Database | Khái niệm Managed Database: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Managed Database để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| IAM | Khái niệm IAM: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng IAM để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Networking | Khái niệm Networking: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Networking để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |

## 4. Kiến thức cần có trước

Cần nắm [CI/CD](../03-ci-cd/README.md) trước khi học nội dung này.

## 5. Công nghệ và công cụ liên quan

pytest, Docker, GitHub Actions, cloud và hệ thống monitoring.

## 6. Ứng dụng trong dự án thực tế

Sẽ được dùng để dùng compute để xử lý hoặc đánh giá dữ liệu novacommerce có thể đối chiếu. trong các project NovaCommerce, cùng bằng chứng về chất lượng hoặc kết quả.

## 7. Kết quả mong đợi

Người học có thể giải thích Compute, Object Storage, Managed Database, IAM, Networking, nhận diện đầu vào/ràng buộc và chọn cách áp dụng phù hợp.

## 8. Học tiếp nội dung nào?

Tiếp tục [Monitoring and Logging](../05-monitoring-and-logging/README.md).
