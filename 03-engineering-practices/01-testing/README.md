# Testing

## 1. Tổng quan

Testing thuộc [Engineering Practices](../README.md), tập trung vào năng lực cần dùng khi làm việc với dữ liệu thực tế.

## 2. Tại sao cần học?

Kiến thức này giúp tránh quyết định kỹ thuật dựa trên giả định và tạo đầu ra dữ liệu có thể kiểm chứng.

## 3. Kiến thức sẽ học

| Concept | Nội dung sẽ học | Ứng dụng |
|---|---|---|
| Unit Testing | Khái niệm Unit Testing: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Unit Testing để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Integration Testing | Khái niệm Integration Testing: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Integration Testing để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Data Assertions | Khái niệm Data Assertions: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Data Assertions để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Test Fixtures | Khái niệm Test Fixtures: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Test Fixtures để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Regression Testing | Khái niệm Regression Testing: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Regression Testing để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |

## 4. Kiến thức cần có trước

Không có prerequisite bắt buộc ngoài điểm xuất phát đã mô tả trong README gốc.

## 5. Công nghệ và công cụ liên quan

pytest, Docker, GitHub Actions, cloud và hệ thống monitoring.

## 6. Ứng dụng trong dự án thực tế

Sẽ được dùng để dùng unit testing để xử lý hoặc đánh giá dữ liệu novacommerce có thể đối chiếu. trong các project NovaCommerce, cùng bằng chứng về chất lượng hoặc kết quả.

## 7. Kết quả mong đợi

Người học có thể giải thích Unit Testing, Integration Testing, Data Assertions, Test Fixtures, Regression Testing, nhận diện đầu vào/ràng buộc và chọn cách áp dụng phù hợp.
