# Data Engineering & Data Analytics Learning Roadmap

Repository là khung học tập từ Foundation đến Senior, ưu tiên **70% Data Engineering** và **30% Data Analytics**. Toàn bộ module và project hiện ở trạng thái **chưa hoàn thành**.

## Định hướng công nghệ

Python là ngôn ngữ chính; SQL và PostgreSQL là nền tảng bắt buộc. Các công nghệ sẽ được tiếp cận theo nhu cầu: pandas, Airflow, dbt, Docker, cloud, PySpark, Kafka và Metabase.

## Thứ tự học đề xuất

Bắt đầu với Foundations; học Data Engineering song song với SQL và Python; bổ sung Data Analytics sau khi dữ liệu đã có cấu trúc; dùng Engineering Practices khi project bắt đầu có nhiều bước vận hành. Chỉ học một concept trong một lần, rồi diễn giải lại bằng phương pháp Feynman: giải thích bằng lời đơn giản, chỉ ra chỗ chưa rõ, quay lại module liên quan và diễn giải lại.

## Module và project liên kết thế nào?

Module cung cấp năng lực; project yêu cầu kết hợp các năng lực đó trong một bối cảnh giả lập. Chỉ chọn project khi đã đáp ứng phần Prerequisites trong README của project.
