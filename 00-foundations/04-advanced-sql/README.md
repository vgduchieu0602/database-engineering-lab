# Advanced SQL

## 1. Tổng quan

Advanced SQL thuộc [Foundations](../README.md), tập trung vào năng lực cần dùng khi làm việc với dữ liệu thực tế.

## 2. Tại sao cần học?

Kiến thức này giúp tránh quyết định kỹ thuật dựa trên giả định và tạo đầu ra dữ liệu có thể kiểm chứng.

## 3. Kiến thức sẽ học

| Concept | Nội dung sẽ học | Ứng dụng |
|---|---|---|
| CTE | Khái niệm CTE: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng CTE để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Window Functions | Khái niệm Window Functions: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Window Functions để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Subqueries | Khái niệm Subqueries: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Subqueries để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Set Operations | Khái niệm Set Operations: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Set Operations để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Query Plans | Khái niệm Query Plans: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Query Plans để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |

## 4. Kiến thức cần có trước

Cần nắm [SQL Fundamentals](../03-sql-fundamentals/README.md) trước khi học nội dung này.

## 5. Công nghệ và công cụ liên quan

Python, PostgreSQL, Git và Bash.

## 6. Ứng dụng trong dự án thực tế

Sẽ được dùng để dùng cte để xử lý hoặc đánh giá dữ liệu novacommerce có thể đối chiếu. trong các project NovaCommerce, cùng bằng chứng về chất lượng hoặc kết quả.

## 7. Kết quả mong đợi

Người học có thể giải thích CTE, Window Functions, Subqueries, Set Operations, Query Plans, nhận diện đầu vào/ràng buộc và chọn cách áp dụng phù hợp.

## 8. Học tiếp nội dung nào?

Tiếp tục [Relational Databases](../05-relational-databases/README.md).
