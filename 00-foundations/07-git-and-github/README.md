# Git and GitHub

## 1. Tổng quan

Git and GitHub thuộc [Foundations](../README.md), tập trung vào năng lực cần dùng khi làm việc với dữ liệu thực tế.

## 2. Tại sao cần học?

Kiến thức này giúp tránh quyết định kỹ thuật dựa trên giả định và tạo đầu ra dữ liệu có thể kiểm chứng.

## 3. Kiến thức sẽ học

| Concept | Nội dung sẽ học | Ứng dụng |
|---|---|---|
| Repository & Commit | Khái niệm Repository & Commit: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Repository & Commit để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Branching | Khái niệm Branching: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Branching để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Pull Request | Khái niệm Pull Request: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Pull Request để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Merge Conflict | Khái niệm Merge Conflict: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Merge Conflict để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Documentation | Khái niệm Documentation: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Documentation để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |

## 4. Kiến thức cần có trước

Cần nắm [Linux and Shell](../06-linux-and-shell/README.md) trước khi học nội dung này.

## 5. Công nghệ và công cụ liên quan

Python, PostgreSQL, Git và Bash.

## 6. Ứng dụng trong dự án thực tế

Sẽ được dùng để dùng repository & commit để xử lý hoặc đánh giá dữ liệu novacommerce có thể đối chiếu. trong các project NovaCommerce, cùng bằng chứng về chất lượng hoặc kết quả.

## 7. Kết quả mong đợi

Người học có thể giải thích Repository & Commit, Branching, Pull Request, Merge Conflict, Documentation, nhận diện đầu vào/ràng buộc và chọn cách áp dụng phù hợp.

## 8. Học tiếp nội dung nào?

Tiếp tục [Data Fundamentals](../08-data-fundamentals/README.md).
