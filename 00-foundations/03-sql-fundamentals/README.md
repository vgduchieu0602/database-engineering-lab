# SQL Fundamentals

## 1. Tổng quan

SQL Fundamentals thuộc [Foundations](../README.md), tập trung vào năng lực cần dùng khi làm việc với dữ liệu thực tế.

## 2. Tại sao cần học?

Kiến thức này giúp tránh quyết định kỹ thuật dựa trên giả định và tạo đầu ra dữ liệu có thể kiểm chứng.

| Concept | Nội dung sẽ học | Ứng dụng |

| NULL Handling | Khái niệm NULL Handling: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng NULL Handling để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |

## 4. Kiến thức cần có trước

Cần nắm [Python for Data](../02-python-for-data/README.md) trước khi học nội dung này.

## 5. Công nghệ và công cụ liên quan

Python, PostgreSQL, Git và Bash.

## 6. Ứng dụng trong dự án thực tế

Sẽ được dùng để dùng select & filtering để xử lý hoặc đánh giá dữ liệu novacommerce có thể đối chiếu. trong các project NovaCommerce, cùng bằng chứng về chất lượng hoặc kết quả.

## 7. Kết quả mong đợi

Người học có thể giải thích SELECT & Filtering, Aggregation, JOIN, NULL Handling, Data Modification, nhận diện đầu vào/ràng buộc và chọn cách áp dụng phù hợp.
