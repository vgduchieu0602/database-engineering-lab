# Data Formats

## 1. Tổng quan

Data Formats thuộc [Foundations](../README.md), tập trung vào năng lực cần dùng khi làm việc với dữ liệu thực tế.

## 2. Tại sao cần học?

Kiến thức này giúp tránh quyết định kỹ thuật dựa trên giả định và tạo đầu ra dữ liệu có thể kiểm chứng.

## 3. Kiến thức sẽ học

| Concept | Nội dung sẽ học | Ứng dụng |
|---|---|---|
| CSV | Khái niệm CSV: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng CSV để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| JSON | Khái niệm JSON: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng JSON để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Parquet | Khái niệm Parquet: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Parquet để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Avro | Khái niệm Avro: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Avro để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Serialization | Khái niệm Serialization: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Serialization để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |

## 4. Kiến thức cần có trước

Cần nắm [Statistics Fundamentals](../09-statistics-fundamentals/README.md) trước khi học nội dung này.

## 5. Công nghệ và công cụ liên quan

Python, PostgreSQL, Git và Bash.

## 6. Ứng dụng trong dự án thực tế

Sẽ được dùng để dùng csv để xử lý hoặc đánh giá dữ liệu novacommerce có thể đối chiếu. trong các project NovaCommerce, cùng bằng chứng về chất lượng hoặc kết quả.

## 7. Kết quả mong đợi

Người học có thể giải thích CSV, JSON, Parquet, Avro, Serialization, nhận diện đầu vào/ràng buộc và chọn cách áp dụng phù hợp.

## 8. Học tiếp nội dung nào?

Đây là module cuối nhóm; hãy chọn module liên quan ở README nhóm hoặc project có prerequisite phù hợp.
