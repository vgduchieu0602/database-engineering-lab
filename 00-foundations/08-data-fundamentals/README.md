# Data Fundamentals

## 1. Tổng quan

Data Fundamentals thuộc [Foundations](../README.md), tập trung vào năng lực cần dùng khi làm việc với dữ liệu thực tế.

## 2. Tại sao cần học?

Kiến thức này giúp tránh quyết định kỹ thuật dựa trên giả định và tạo đầu ra dữ liệu có thể kiểm chứng.

## 3. Kiến thức sẽ học

| Concept | Nội dung sẽ học | Ứng dụng |
|---|---|---|
| Data Lifecycle | Khái niệm Data Lifecycle: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Data Lifecycle để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Data Sources | Khái niệm Data Sources: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Data Sources để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Schema | Khái niệm Schema: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Schema để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Data Validation | Khái niệm Data Validation: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Data Validation để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Data Lineage | Khái niệm Data Lineage: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Data Lineage để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |

## 4. Kiến thức cần có trước

Cần nắm [Git and GitHub](../07-git-and-github/README.md) trước khi học nội dung này.

## 5. Công nghệ và công cụ liên quan

Python, PostgreSQL, Git và Bash.

## 6. Ứng dụng trong dự án thực tế

Sẽ được dùng để dùng data lifecycle để xử lý hoặc đánh giá dữ liệu novacommerce có thể đối chiếu. trong các project NovaCommerce, cùng bằng chứng về chất lượng hoặc kết quả.

## 7. Kết quả mong đợi

Người học có thể giải thích Data Lifecycle, Data Sources, Schema, Data Validation, Data Lineage, nhận diện đầu vào/ràng buộc và chọn cách áp dụng phù hợp.
