# System Design

## 1. Tổng quan

System Design thuộc [Data Engineering](../README.md), tập trung vào năng lực cần dùng khi làm việc với dữ liệu thực tế.

## 2. Tại sao cần học?

Kiến thức này giúp tránh quyết định kỹ thuật dựa trên giả định và tạo đầu ra dữ liệu có thể kiểm chứng.

| Concept | Nội dung sẽ học | Ứng dụng |
|---|---|---|

| Failure Modes | Khái niệm Failure Modes: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Failure Modes để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |

## 4. Kiến thức cần có trước

Cần nắm [Data Governance and Security](../13-data-governance-and-security/README.md) trước khi học nội dung này.

## 5. Công nghệ và công cụ liên quan

Python, PostgreSQL, dbt, Airflow, object storage và công cụ quan sát.

## 6. Ứng dụng trong dự án thực tế

Sẽ được dùng để dùng requirements analysis để xử lý hoặc đánh giá dữ liệu novacommerce có thể đối chiếu. trong các project NovaCommerce, cùng bằng chứng về chất lượng hoặc kết quả.

## 7. Kết quả mong đợi

Người học có thể giải thích Requirements Analysis, Capacity Estimation, Architecture Patterns, Failure Modes, Trade-offs, nhận diện đầu vào/ràng buộc và chọn cách áp dụng phù hợp.

## 8. Học tiếp nội dung nào?

Đây là module cuối nhóm; hãy chọn module liên quan ở README nhóm hoặc project có prerequisite phù hợp.
