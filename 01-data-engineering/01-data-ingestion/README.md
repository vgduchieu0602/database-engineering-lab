# Data Ingestion

## 1. Tổng quan

Data Ingestion thuộc [Data Engineering](../README.md), tập trung vào năng lực cần dùng khi làm việc với dữ liệu thực tế.

## 2. Tại sao cần học?

Kiến thức này giúp tránh quyết định kỹ thuật dựa trên giả định và tạo đầu ra dữ liệu có thể kiểm chứng.

## 4. Kiến thức cần có trước

Không có prerequisite bắt buộc ngoài điểm xuất phát đã mô tả trong README gốc.

## 5. Công nghệ và công cụ liên quan

Python, PostgreSQL, dbt, Airflow, object storage và công cụ quan sát.

## 6. Ứng dụng trong dự án thực tế

Sẽ được dùng để dùng batch ingestion để xử lý hoặc đánh giá dữ liệu novacommerce có thể đối chiếu. trong các project NovaCommerce, cùng bằng chứng về chất lượng hoặc kết quả.

## 7. Kết quả mong đợi

Người học có thể giải thích Batch Ingestion, API Pagination, Schema Discovery, Retry Strategy, Landing Zone, nhận diện đầu vào/ràng buộc và chọn cách áp dụng phù hợp.
