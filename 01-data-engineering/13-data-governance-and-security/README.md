# Data Governance and Security

## 1. Tổng quan

Data Governance and Security thuộc [Data Engineering](../README.md), tập trung vào năng lực cần dùng khi làm việc với dữ liệu thực tế.

## 2. Tại sao cần học?

Kiến thức này giúp tránh quyết định kỹ thuật dựa trên giả định và tạo đầu ra dữ liệu có thể kiểm chứng.

## 3. Kiến thức sẽ học

| Concept | Nội dung sẽ học | Ứng dụng |
|---|---|---|
| Data Classification | Khái niệm Data Classification: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Data Classification để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Access Control | Khái niệm Access Control: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Access Control để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Encryption | Khái niệm Encryption: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Encryption để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Data Retention | Khái niệm Data Retention: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Data Retention để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |
| Audit Trail | Khái niệm Audit Trail: mục đích, dữ liệu liên quan, giới hạn và dấu hiệu dùng sai. | Dùng Audit Trail để xử lý hoặc đánh giá dữ liệu NovaCommerce có thể đối chiếu. |

## 4. Kiến thức cần có trước

Cần nắm [Performance Optimization](../12-performance-optimization/README.md) trước khi học nội dung này.

## 5. Công nghệ và công cụ liên quan

Python, PostgreSQL, dbt, Airflow, object storage và công cụ quan sát.

## 6. Ứng dụng trong dự án thực tế

Sẽ được dùng để dùng data classification để xử lý hoặc đánh giá dữ liệu novacommerce có thể đối chiếu. trong các project NovaCommerce, cùng bằng chứng về chất lượng hoặc kết quả.

## 7. Kết quả mong đợi

Người học có thể giải thích Data Classification, Access Control, Encryption, Data Retention, Audit Trail, nhận diện đầu vào/ràng buộc và chọn cách áp dụng phù hợp.

## 8. Học tiếp nội dung nào?

Tiếp tục [System Design](../14-system-design/README.md).
